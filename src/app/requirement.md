タスク管理アプリ

目的：
　チームマネージャーの求める情報の質を落とすことなく、メンバーのタスク管理の負担を最大限削減すること

機能：

　ページ種類：
　（管理者側）
　0.初期設定（プロジェクト作成、アクセス権限の付与）
　1.親タスク管理ページ（トップページ）
　2.プロジェクト作成ページ
　3.新規/既存メンバー追加ページ
　4.メンバータスク詳細ページ
　5.完了タスク一覧ページ
　6.共有ページ

　（メンバー側）
　1.今日やること一覧ページ（トップページ）
　2.付与タスク一覧（期限付き）ページ
　3.期限未設定タスク一覧ページ
　4.完了タスク一覧ページ
　5.共有ページ

　
　○初期設定について
　　
　　1.プロジェクト作成、アクセス権限の付与
　　→
    プロジェクト立ち上げ時に表示
　　初期画面でプロジェクト名、メンバーの追加、アクセス権限の付与等の設定を行う。
　　初期設定した後から別プロジェクトの作成をする場合は「親タスク管理ページ」のプロジェクト作成ボタンで
　　「プロジェクト作成ページ」に飛び、メンバーとアクセス権限設定を行う。メンバー登録についてはすでに別プロジェクトに
　　参加しているメンバーからも選択できるし、新規で名前を登録することもできる。

　　2.メンバーの登録、追加
　　→
　　初期ではプロジェクト作成時にメンバーの登録を行う。
　　それ以降途中の追加については「親タスク管理ページ」の「メンバー追加」ボタンから登録する。
　
　①親タスク管理ページについて：管理者
　　
　　・画面左側にボタンが集約されており、上から「タイトル欄」、「期限と緊急ボタン」、「担当｜メンバーボタン」、「備考欄」、「共有ボタン」、「確定ボタン」がある。
　　　その下には「設定未完成タスク一覧」があり、親タスクを登録する際に未入力項目があるものだけここに表示される。これは画面の情報量が多くならないよう
　　　一覧は折りたたまれて表示され、見たい時だけ広げて表示させる。

　　・画面の中央には必要項目がすべて入力されているタスク一覧が表示されている。

　　　表示されている各タスクが表示されている範囲の左側には、期限、タイトル、備考、担当者と複数メンバーで実施する場合はメンバーが顔写真と名前付き　　　
　　　で表示されている。タイトル部分にはステータスが表示されており、「未着手」、「進行中」、「完了」のいずれかが表示される。

　　　右側には子タスクの追加フォームがあり、タイトルを入力し、担当する人を選んで追加する。するとフォーム下に子タスク一覧が表示される。
    　表示されている子タスクでは、タイトル左側に進捗ステータス、右側にメンバーの顔写真があり、メンバーの進捗状況が吹き出しで表示される。

　　・右上には設定マークのボタンがあり、そこを押すと隠れていた「メンバータスク詳細」、「プロジェクト作成」、「新規/既存メンバー追加」、
      「完了タスク一覧」ページに飛ぶボタンが出てくる。
　　
　　　→
　　　緊急ボタンを押したタスクは、タスクに緊急マークが表示され、自動で順番の上位に来る。

　　　入力する情報量によって挙動を変える。詳細はなくても登録は可能。
　　　→
　　1.タイトルのみ
　　　→
　　　「設定未完成タスク一覧」へ行く。まだ管理側のみ表示

　　2.タイトルと期限のみ
　　　→
　　　「設定未完成タスク一覧」へ行く。入力された期限を強調して管理側のみ表示。

　　3.タイトル、担当名のみ
　　　→
　　　「設定未完成タスク一覧」と画面中央のタスク一覧に表示。そして担当の「期限未設定タスク一覧ページ」へ行く。
　　　　管理側では入力された担当名と顔写真を強調して表示される。

　　4.タイトル、期限、担当名
　　　→
　　　「付与タスク一覧（期限付き）ページ」へ行く。管理側画面中央のタスク一覧にも表示される。

　　・タスクを入力すると、1～3のタスクのみがフォーム下の「設定未完成タスク一覧」に追加され表示される。　
　　・未完成タスクは一覧部分で期限、担当者、削除、タイトルの編集が可能。
　　・ここのタスク一覧は「各1～3のみ一覧」、「1～3すべて一覧」に表示を切り替えることができる。　　　　　　　　　　　　　　　　　　　　　　　　　　　　　
　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　↓
　　　　　　　　　　　全メンバーのタスク一覧を見ながらタスクの作成登録ができ、設定が未完成のタスクも一目でわかる。
　　　　　　　　　　　また、最初にやるタスクの書き出しをここでできる。
　　
　②プロジェクト作成ページ：管理者
　　→
　　プロジェクトを作成するページ。プロジェクト名を登録後、メンバーの登録、追加、メンバーごとの権限の付与を行う。
　
　③新規/既存メンバー追加ページ：管理者
　　→
　　新規メンバーの追加、登録済みメンバーの各タスクへの割り振りを行うページ。ここはプロジェクト作成時以外でメンバーを追加する場合に用いる。
　　各タスクへの割り振りの際は権限の付与もここで行う。

  ④メンバータスク詳細ページ：管理者
　　→
　　顔写真付きでメンバー一覧が表示されていて、カーソルを合わせるとそのメンバーの受け持っているタスク一覧が表示される。
　　ここではメンバーのMYタスクも表示される。メンバーごとの受け持っているタスク量をここで把握することで負担の偏りを調整する。
  
  ⑤完了タスク一覧ページ：管理者
　　→
　　完了したタスク一覧が表示される。各タスクが完了したときは、15分間時間を空けてここのページに移動される。
　　メンバー画面では、子タスクがすべて完了すると自動で親タスクのステータスが完了になる。その後子タスクが追加される可能性を考慮して
　　15分空ける。
　

　⑥種類別のタスク一覧ページ：メンバー
　　
　　1.今日やること一覧ページ
　　　→
　　　画面左側には「MYタスク作成」フォームがある。上から「タイトル欄」、「備考欄」、「確定ボタン」がある。
　　　画面中央には今日やることの一覧が表示されており、ここでは今日中に行う親タスクだけでなく子タスクも表示される。
　　　子タスクが表示されているところには、タイトル、ステータス、ステータス変更ボタン（未着手、進行中、完了）のみ。
　　　親タスクが表示されているところについては親タスク管理ページ：管理者とほぼ同じで、子タスクを作成、
　　　表示される部分があり、異なるのはステータス変更ボタンがついていること。

　　2.付与タスク一覧ページ
　　　→
　　　今日やるページ同様に画面左側にMYタスク追加フォームがあるが、このページでは期限も設定する。

　　　画面中央には管理者から付与された期限付きの親タスク一覧が表示されており、子タスク追加フォームもある。ここでは子タスクのタイトル、担当者／メンバー、
      期限or今日やるボタンを設置しており、今日やるボタンを押した子タスクや、期限が今日の親タスクなどは自動で今日やること一覧ページに飛ぶ。

　　　子タスクのフォームクリック時に期限調整できるカレンダーを表示(親タスク期限までの期間のみ表示)

　　3.期限未設定タスク一覧ページ
　　　→
　　　管理から付与されたタスクで、タイトル(詳細)、担当者は設定されているが期限が未設定であるものがここに表示される。ここでは親タスクの期限、メンバー追加、
      今日やるボタン、子タスクの追加等設定ができる。

    ・親タスクのステータス管理
　　　 →
　　　 親タスクについては、設定した子タスクによって自動でステータスが更新される。
　　　 子タスクがすべて完了していない場合は「進行中」、すべて終わったら「完了」となる。
　　　 複数人で一つのタスクを進めている場合、メンバーすべての子タスクのステータスが完了してから親タスクも完了となる。
　　　 親タスクにもステータスを変更するボタンはあるが、使うのは子タスクの設定をしていない時。

　  ・通知オフボタン
　　　 →
　　　 通知が頻繁に来て、一時的にオフにしたい場合に、時間を指定してその期間だけオフにできる。
　　　 このボタンは全ページについている。

    ・進捗報告機能について
　　　 →
　　　 親タスクが開始してから期限の10%経過した際に自動で確認の通知がくる。通知には「もう終わる」「今のところ問題なし」「停滞中」の３つのボタンがあり、
　　　 一回通知が来てボタンを押すと、それ以降は通知は来ない。この後解説する相談AI機能を使用している場合にはその質問が終わった15分後に通知を送る。

　　　 管理者側画面にはメンバーの現状が吹き出しで表示され、質問中のメンバーのところには質問中と表示される。この一回以降は、「もう終わる」、「今のところ問題なし」
　　　 を押した人が停滞していた時だけ「停滞中」ボタンを、停滞していた人が解決した時だけ「今のところ問題なし」、「もう終わる」ボタンを押す。

　　　 その間の詳細な進捗状況については、AIに相談した内容をログとして記録するためそのログを元に報告文を生成してもらい、管理側に吹き出しで通知する。
　　 
    ・相談AIキャラクターについて
　　　 →
　　　 タスク進行中に問題が起きた時、相談AIを活用する。このAIに相談することで相談内容、それに対する回答が一つのDBにナレッジとして記録され、
　　　 他の人が同じ問題にぶつかった時に記録されているナレッジを元にAIが回答をしてくれる。ナレッジが蓄積されるほど回答の精度があがっていく。

　　　 このアプリでは、AIを活用することで実力を発揮するため、ユーザーが積極的に活用するようにさせる必要がある。
　　　 そこで相談AI機能をツールとしてでなく仲間として認知してもらうために、キャラクターを画面上に表示させる。
　　　 このキャラクターは実際に生きているかのように、画面の至るところを歩いたり、座ってリラックスしたり、寝そべったりと人間的アクションを取ったり、
　　　 テキストで話しかけてきたりする。作業の邪魔にならないサイズで、視界に頻繁に入るよう行動させ、また停滞している際に声をかけてきたりなどすることで
　　　 単純接触効果と親しみやすさを感じさせて、AIに相談することが当たり前であるという感覚にさせる。

　⑦完了タスク一覧ページ：メンバー
　　
　　　自分のタスクで完了したものが全て表示される。親タスクのステータスが完了となってから10分後には自動で完了タスク一覧に移動する。
　　　　（15分間は管理側も「完了（移動待ち）」と表示される。）
　
　⑧共有タスク一覧ページ：（管理、メンバー）
　　　
　　　共有ボタンが押された親タスク一覧が表示される。
      　　　　
　⑧タスク並び替え（優先順位付け）

　　親タスクを作成すると、期限ありの場合は期限が近い順で自動並び替えされる。
　　緊急ボタンを押しているタスクは登録時に自動で上位に表示される。
　　順を変える場合はクリックアンドドロップで移動させる。

　⑨通知、リマインド（背景色でも通知）

　　期限未設定タスクがある場合はログイン、ログアウト時に確認のリマインドを通知
　　管理側が親タスクの変更をした際に、メンバーに通知がいくようにする。
　　期限の残り期間によって、表示されているタスクの背景色を変える　
　　（期限まで一週間以上あれば「緑」、三日前で「黄」、今日であれば「赤」）
　　

　⑩ログイン機能とアクセス権限

　　権限については「管理者」、「メンバー」、「ゲスト」で分ける。
　　管理者はすべてのプロジェクト、タスクの閲覧、編集ができる。メンバーは自分のタスクの閲覧、編集ができる。
　　ゲストはタスクの閲覧のみ。ログインについてはGoogleのソーシャルログイン
